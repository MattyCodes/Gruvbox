# Slack Gruvbox Themes
[👈 Home](../README.md)

Tragically, Slack no longer allows you to actually save and automate switching between custom themes. 🙃

The best that can be done now is to just copy the list of hexidecimal colors and paste them into your Slack settings under `Appearance -> Custom Theme -> Import` and then save.

### Dark Theme
`#282828,#928374,#689D6A,#FB4934`

### Light Theme
`#FBF1C7,#7C6F64,#689D6A,#CC241D`
